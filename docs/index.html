dsh-ai4s-stack

两个 DSH（DeepSeek Harness） 插件打包在一起：一个管「装什么能力」，一个管「怎么自动干活」。一条命令装完。

MIT panel 2.3.16 composer 1.0.0 Windows / macOS / Linux 零运行时依赖

两个插件

技能 + MCP 面板

dsh-skill-mcp-panel

web 侧栏管理 skills 与 MCP servers，含统一 CLI。

  • 技能分组 / 导入 / 迁移
  • MCP 服务器增删改、探活、OAuth
  • CLI：dsh-panel

全自动 AI4S 模式

dsh-ai4s-composer

四档编排：自动决定开不开子代理、开几个、用哪个模型。

  • quick / solo / delegate / cluster
  • 子代理强制只读，执行动作回到主代理
  • 结论经 systemPrompt 回灌

一键安装

Windows · PowerShell
& ([scriptblock]::Create((irm https://github.com/SESZFY/dsh-ai4s-stack/raw/main/install.ps1)))
macOS / Linux / WSL · bash
curl -fsSL https://github.com/SESZFY/dsh-ai4s-stack/raw/main/install.sh | bash
带参数（指定 profile、直接切集群模式）
& ([scriptblock]::Create((irm https://github.com/SESZFY/dsh-ai4s-stack/raw/main/install.ps1))) `
    -Profile web -Mode cluster -ClusterModel "openrouter/deepseek-v3.2"

桌面端（desktop profile）由 Electron 独占，CLI 装不进去。用 .\install.ps1 -Profile desktop -Manual -Apply 走清单补丁模式，或直接在 DSH 的「设置 → 插件」里装。

安装器做了什么

步骤说明
1探测 node / pnpm / dsh CLI / $DSH_HOME/profiles/*
2缺 pnpm 就 npm i -g pnpm（dsh plugin 的底层依赖）
3下载本仓库源码到缓存目录，只下一次
4调官方 dsh plugin --profile <name> add <目录>，两个包各一条
5回读 profile 的 package.json，确认两个包都进了 dsh.profile.bundles
6可选：写入 AI4S 模式偏好

四种模式

模式行为
quick不开子代理，主代理直接做
solo原生行为，默认值
delegate每轮自动开 1 个只读子代理，结论回灌
cluster先规划拆分子任务，再并行开多个子代理，可中途追加
